Experiment Insight

SMOTE was tested to address class imbalance, but it reduced overall Macro F1 compared with the baseline XGBoost model. Therefore, SMOTE was not selected for the final model.

Baseline XGBoost Macro F1 = 0.7441
XGBoost + SMOTE Macro F1 = 0.7278
Tuned XGBoost Macro F1 = 0.7593
